示例预览 · 脚本运行后将在 B 站页面显示

它不猜测你看了多久，它只记录真正发生过的播放。

真正在播的每一秒都会被记下来，没在看的时段不会混进来。

观看时长不是猜出来的。

很多时间统计会把挂着没看的时段也算进去。这个面板只认真实播放过的时间，你可以随时打开核对。

01

暂停、缓冲、切到别的标签页，都不算进时长。

只有视频真的在走，时间才往前走。脚本每隔几秒对一次表，只把真正播放的部分记下来。

没在播就不计时
02

看到一半去干别的，它不会当成你一直在看。

每次播放从开始到结束算一段，中途暂停、跳进度、关掉页面都会记下来，所以每条时长都站得住。

时长经得起核对
03

看到过了半夜，两天的时长也不会算错。

跨零点的观看会按日期切开，分别算进前一天和后一天，既不漏记也不会重复计算。

跨天也不会重复计
视频、番剧、课程 覆盖 /video、/bangumi/play 与 /cheese/play 三类播放页。
分 P 与分集 mediaKey 会保留分 P 或分集序号，避免不同内容混成一条记录。
JSON 导入导出 换浏览器时由你主动导出和导入，合并记录并去重会话。
周报 PNG 把本周总览、最爱 UP 主和每日时长整理成一张可保存的报告。

安装路径 Tampermonkey

三步装好，让观看记录开始留下来。

先装浏览器扩展 Tampermonkey，再点击本站的安装脚本。确认一次，打开任意 B 站视频页，右侧就会出现可拖动的观看数据入口。

Install flow

照着做，半分钟就能开始记录。

打开完整安装说明
  1. 浏览器扩展

    打开 Tampermonkey 官网，按浏览器选择对应版本并完成安装。

    去官网安装

  2. 回到本站，点击“ 一键安装脚本 ”。Tampermonkey 会自动打开确认页，点一次安装即可。

    立即安装脚本

  3. 打开任意 B 站视频页，播放几秒钟，右侧会出现可以拖动的面板入口。

    数据只保存在当前浏览器
