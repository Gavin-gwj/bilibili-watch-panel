## 5. 已知限制

| 项 | 说明 |
| --- | --- |
| 统计口径 | 按 `video.currentTime` 推进量累加，不乘倍速；卡顿/缓冲不计入 |
| 多标签页 | 同一视频在两标签同时播放时，极端情况下可能少记少量时长 |
| 分 P 视频 | v0.1.0 以 BV 为单位合并，同一 BV 的不同分 P 视为同一视频 |
| 番剧 / 直播 | 仅支持 `/video/` 路径，番剧与直播不统计 |
| 数据导入 | 0.3.0 起支持 JSON 导入合并（同天同视频取较大时长，不做时长累加） |
| 自动化测试 | 未引入测试框架，采用节点冒烟 + 手工浏览器自测 |
