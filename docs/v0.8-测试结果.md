## 4. 验证过程中修复的问题

| 问题 | 修复与复测 |
| --- | --- |
| 快速输入后进入设置，220ms 搜索防抖尚未执行 | 进入设置立即保留输入；延迟回调不重建设置页；移除测试等待后仍通过 |
| Chart.js 运行时 options 代理重复赋值导致栈溢出，PNG 图表空白 | 改为更新 `chart.config.options`；截图前停止动画并浅色重画，随后恢复深色；真实下载 PNG 已目视复核 |
| toast 使用硬编码白色背景，深色文字可能不可读 | 背景、边框、文字统一使用主题令牌 |
| 缩小后放大视口，右侧按钮可能被误判到左侧 | 运行时保留左右锚点，存储仍兼容旧 {x,y}，不用数据迁移 |
| 会话非有限起止时间被旧清洗条件接受 | 增加有限数值检查；旧记录与合法会话兼容测试通过 |

## 6. 可复现命令

在仓库根目录执行（PowerShell）：

```powershell
node --check bilibili-watch-panel.user.js
node tests/v0.8.test.cjs
git diff --check

# 一个终端启动仅监听 127.0.0.1 的合成测试页；Ctrl+C 结束
node tests/browser-fixture.cjs

# 另一个终端运行浏览器验证，首次使用需有 Chrome / Playwright CLI
npx --yes --package @playwright/cli playwright-cli -s=bwp08 open http://127.0.0.1:18768 --browser chrome
npx --yes --package @playwright/cli playwright-cli -s=bwp08 run-code --filename tests/browser-check.js
npx --yes --package @playwright/cli playwright-cli -s=bwp08 close
```

测试页的 GM 模拟与 testApi 暴露只由测试服务器临时注入，**不包含在正式用户脚本**。重新打开测试配置会保留其 localStorage，但不影响真实 B 站/油猴存储。
